# RTK

Token-optimized CLI proxy for dev command output.

A Claude Code hook auto-rewrites (`git status` -> `rtk git status`). Elsewhere invoke `rtk <cmd>`.

- `rtk gain [--history]` savings analytics
- `rtk discover` missed opportunities in agent history
- `rtk proxy <cmd>` raw passthrough, no filtering

`rtk gain` errors -> wrong `rtk` on PATH. Check `rtk --version`.
